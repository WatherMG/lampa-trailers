# Security policy

This project is a **beta** plugin that runs inside Lampa's webview and talks directly to third-party media services. It does not operate a proxy or store service credentials.

Do not post private CDN links, signed playback URLs, account identifiers, cookies or diagnostic logs containing them in public issues. Redact such data before opening an issue.

To report a security concern, use the repository's **Security → Report a vulnerability** feature if private vulnerability reporting is enabled. Otherwise contact the repository owner privately via GitHub; do not include an exploit or secrets in a public issue.

Supported releases: the current `main` branch is experimental; fixes are applied to `main` until a stable release is published.
